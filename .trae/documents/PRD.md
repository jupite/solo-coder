## 1. 产品概述

基于Three.js的3D架子鼓节奏游戏，玩家需要在彩色音符下落到对应鼓面时按对应键或点击鼓面进行打击，考验反应力和节奏感。
- 面向所有年龄段的休闲游戏玩家，提供简单易上手但有挑战性的节奏体验
- 核心价值：沉浸式3D视觉体验，紧张刺激的节奏玩法，连击和狂热模式增加游戏深度

## 2. 核心功能

### 2.1 功能模块

1. **游戏主界面**：3D架子鼓场景、音符轨道、UI面板
2. **音符系统**：彩色球体生成、沿轨道下落、节奏生成
3. **打击系统**：键盘检测(F/G/H)、鼠标点击检测、打击时机判定
4. **计分系统**：得分计算、连击计数、狂热模式(10连击)
5. **特效系统**：击中粒子效果、鼓面震动动画、背景节拍可视化
6. **UI显示**：分数、连击数、狂热状态提示

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主界面 | 3D鼓场景 | 三个彩色鼓面(红/蓝/黄)，对应三个音符轨道 |
| 游戏主界面 | 音符系统 | 彩色球体从上方沿轨道下落，到达鼓面时可被击中 |
| 游戏主界面 | 打击检测 | 监听F/G/H按键和鼓面点击，判定打击时机(±0.2秒) |
| 游戏主界面 | 计分显示 | 实时显示当前分数、连击数、狂热状态 |
| 游戏主界面 | 特效系统 | 击中时产生粒子爆炸效果，鼓面发光动画 |
| 游戏主界面 | 节拍可视化 | 背景律动效果，随音乐节拍变化 |

## 3. 核心流程

玩家打开游戏后，音符从上方随机生成并沿轨道下落。当音符接近鼓面时，玩家按对应键或点击鼓面进行打击。若时机准确（误差<0.2秒），则得分+10并触发粒子效果；若错过则扣分。连续击中10次进入狂热模式，得分翻倍。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深色背景配合霓虹色彩
- 鼓面颜色：红色(#FF3366)、蓝色(#3366FF)、黄色(#FFCC00)
- 按钮样式：3D立体效果，带有发光边缘
- 字体：现代无衬线字体，大号数字显示分数
- 布局：全屏3D场景，UI元素悬浮在画面上下方
- 视觉效果：粒子爆炸、发光效果、背景律动

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 游戏主界面 | 3D场景 | 三个鼓面位于底部，轨道从顶部延伸至鼓面 |
| 游戏主界面 | 音符 | 彩色球体，与对应鼓面同色 |
| 游戏主界面 | 分数显示 | 左上角大号数字，白色发光 |
| 游戏主界面 | 连击显示 | 分数下方，黄色数字，狂热模式时红色闪烁 |
| 游戏主界面 | 按键提示 | 鼓面上方显示F/G/H键位标识 |
| 游戏主界面 | 节拍可视化 | 背景随节拍产生光晕波动效果 |

### 4.3 响应式设计

- 桌面端优先，全屏显示
- 支持鼠标和键盘操作
- 自适应窗口大小

### 4.4 3D场景指导

- 环境：深色舞台背景，聚光灯效果
- 光照：三盏点光源分别照射三个鼓面，营造舞台氛围
- 相机：固定视角，从斜上方俯瞰场景
- 构图：三个鼓面水平排列，音符轨道垂直向下
- 交互：鼓面可点击，按键触发打击
- 后处理：发光效果，粒子系统
- 性能：控制粒子数量，优化渲染性能
