## 1. 产品概述
草原骑马射箭游戏，玩家骑在奔跑的马上，瞄准并射击前方的靶子获取分数。
- 目标用户：休闲游戏爱好者，喜欢3D沉浸式体验的玩家
- 产品价值：提供简单有趣的骑马射箭体验，考验玩家的瞄准和时机把握能力

## 2. 核心功能

### 2.1 功能模块
1. **游戏主页**：开始游戏按钮、历史成绩展示、游戏说明
2. **游戏场景**：草原赛道、奔跑的马、靶子、弓箭系统
3. **结算页面**：本次得分、历史最高分、重新开始

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 游戏主页 | 开始按钮 | 点击进入游戏场景，开始30秒倒计时 |
| 游戏主页 | 历史成绩 | 显示玩家历史最高分和最近成绩 |
| 游戏主页 | 游戏说明 | 操作指南和得分规则 |
| 游戏场景 | 骑马系统 | 马自动向前奔跑，带骑马晃动效果 |
| 游戏场景 | 射箭系统 | 鼠标瞄准，长按左键蓄力，松开发射 |
| 游戏场景 | 靶子系统 | 固定靶子和左右移动靶子，射中靶心10分 |
| 游戏场景 | UI界面 | 实时显示当前分数和剩余时间 |
| 结算页面 | 得分展示 | 显示本次得分和历史最高分 |
| 结算页面 | 操作按钮 | 重新开始或返回主页 |

## 3. 核心流程
玩家进入游戏主页，点击开始按钮后进入游戏场景。马自动向前奔跑，玩家使用鼠标瞄准靶子，长按左键蓄力后松开发射箭矢。箭矢沿抛物线飞行，命中靶子根据距离靶心的远近获得相应分数。30秒倒计时结束后进入结算页面，显示本次得分并保存到历史成绩。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：草原绿色 (#4CAF50)、天空蓝色 (#87CEEB)、木质棕色 (#8B4513)
- **按钮样式**：圆角按钮，带阴影悬停效果
- **字体**：标题使用粗体，正文字体清晰易读
- **布局风格**：游戏场景全屏，UI元素悬浮在画面角落
- **图标风格**：使用emoji增强视觉效果 🏹🐎🎯

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 游戏主页 | 开始按钮 | 大号圆角按钮，绿色渐变背景，悬停放大效果 |
| 游戏主页 | 历史成绩 | 卡片式布局，深色背景，金色最高分 |
| 游戏场景 | 准星 | 跟随鼠标的十字准星 |
| 游戏场景 | 蓄力条 | 屏幕底部显示蓄力进度条 |
| 游戏场景 | 分数/时间 | 左上角显示分数，右上角显示倒计时 |
| 结算页面 | 得分展示 | 大号数字显示本次得分 |
| 结算页面 | 操作按钮 | 两个并排按钮：重新开始/返回主页 |

### 4.3 响应式设计
- 桌面端优先设计
- 游戏场景自适应窗口大小
- UI元素使用固定像素尺寸，保持游戏体验一致性

### 4.4 3D场景指南
- **环境**：草原赛道，蓝天白云，远处山脉
- **光照**：方向光模拟阳光，环境光补充
- **相机**：第三人称视角，跟随马背
- **焦点**：前方的靶子区域
- **交互**：鼠标控制瞄准，长按蓄力
- **动画**：马奔跑动画、骑马晃动、箭矢抛物线
- **后期处理**：色彩校正、轻微泛光效果
